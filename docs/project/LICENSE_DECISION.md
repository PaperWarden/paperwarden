# License decision

**Status:** Accepted for the initial public release.

PaperWarden uses the Apache License 2.0. It is permissive, includes an express
patent grant, and fits the project's intent to remain broadly reusable.

The decision must continue to account for the exact mobile builds and distribution terms
of PDFium, qpdf, LibreOffice components, Tesseract, OpenCV, and all transitive
native dependencies. Revisit this decision before 1.0 if the selected distribution
model or third-party obligations require a compatible adjustment.
