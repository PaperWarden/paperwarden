# Code of Conduct

We are committed to a welcoming, harassment-free project. Be respectful, assume
good intent while evaluating technical claims on evidence, and keep feedback about
the work rather than the person.

Maintainers may remove abusive, discriminatory, threatening, doxxing, spam, or
otherwise unsafe participation. Report conduct concerns privately to the project
maintainers; a dedicated contact address will be published before contributions
open.
